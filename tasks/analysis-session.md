# 保存分析现场与持久书签

新增“保存分析现场 / 打开分析现场”，用独立的 `.wsanalysis` JSON 文件引用抓包文件，
保存显示过滤器、读取过滤器、当前包、标记、忽略、时间参考、列表布局和带标题/备注的书签。
恢复前验证完整抓包 SHA-256；文件移动后可重新定位，内容不匹配时拒绝恢复。
列布局只应用于相同的列定义，避免把另一配置下的列宽和隐藏状态套错。

书签自动保存在用户配置目录，按抓包内容和读取过滤器隔离，复制/改名后的相同文件可复用。
写入使用原子替换和文件锁；损坏数据不会被静默覆盖。校验在后台进行，可在切换文件时取消。
实时或未保存的抓包需要先停止并保存，才能建立可持久定位的书签和现场。

验收：往返恢复、跨进程书签、中文备注、搜索/跳转、被过滤包、同名不同内容、文件移动、
损坏/未来版本/越界 JSON、写入失败、多窗口合并、读取过滤器隔离及原生中文界面。
