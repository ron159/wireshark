# 保存分析现场与持久书签

新增“保存分析现场 / 打开分析现场”，用独立的 `.wsanalysis` JSON 文件引用抓包文件，
保存显示过滤器、读取过滤器、当前包、标记、忽略、时间参考、列表布局和带标题/备注的书签。
恢复前验证完整抓包 SHA-256；文件移动后可重新定位，内容不匹配时拒绝恢复。
列顺序、列宽、可见性和排序按列定义匹配后恢复；定义不同则保留当前布局并提示。
布局采用经过范围校验的显式字段，不接受 Qt 内部二进制状态。

书签自动保存在用户配置目录的 `packet_bookmarks` 中，按抓包内容、读取过滤器及实际接受
的数据包序列隔离，复制/改名后的相同文件可复用。打开旧现场时保留本机后来修改或删除的
书签；仅在本机没有对应书签文件时，导入现场携带的副本。
写入使用原子替换和文件锁；损坏数据不会被静默覆盖。校验在后台进行，可在切换文件时取消。
实时或未保存的抓包需要先停止并保存，才能建立可持久定位的书签和现场。

书签跳转到被过滤的包时，在原过滤器外追加该包号，保留原有匹配结果。
恢复现场保留原显示过滤器；如果保存的选中包被它隐藏，会明确提示。
现场引用抓包文件，不嵌入原始流量，也不打包配置、密钥、临时解码规则或独立统计窗口。
单个现场最多 16 MiB、10,000 个书签；每类标记列表最多 100,000 个包。

验收：往返恢复、跨进程书签、中文备注、搜索/跳转、被过滤包、同名不同内容、文件移动、
损坏/未来版本/越界 JSON、写入失败、多窗口合并、读取过滤器隔离及原生中文界面。
